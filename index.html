Loja virtual de delivery (Nightbox)

Site que fiz como teste para lojas virtuais, usando IA no desenvolvimento. É uma plataforma completa de vendas online, pensada para carregar rápido, funcionar bem no celular e deixar a compra fluida para o cliente.

  • Vitrine dinâmica com navegação por categorias em carrossel.
  • Carrinho lateral com subtotal calculado em tempo real.
  • Sistema de cupons com desconto aplicado na hora.
  • Login e criação de conta, com validação de Gmail e recuperação de senha.
  • Checkout que exige login e gera um Pix instantâneo (QR Code no padrão BACEN), com integração ao SDK do Mercado Pago, sem expor dados sensíveis.

TypeScript e JavaScript · Next.js 14 (App Router) e React 18 · Tailwind CSS (tema escuro responsivo) · API Routes do Next.js (Node.js) · Supabase (PostgreSQL) · Mercado Pago SDK · Vercel (deploy contínuo).
